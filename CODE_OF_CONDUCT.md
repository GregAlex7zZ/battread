# Code of conduct

Treat contributors and users respectfully. Discuss scientific interpretations
and implementation choices using evidence. Harassment, discrimination and
sharing private information without consent are unacceptable.

Maintainers should address reported concerns fairly and protect personal
information. The responsible maintainer is Alessandro Gregucci. Use the
repository's GitHub Issues for nonsensitive community concerns or to request
a private reporting channel. Do not disclose personal information, private
acquisitions or sensitive allegations in a public issue. Withhold sensitive
details until a suitable private channel has been agreed with the maintainer.
Security vulnerabilities follow SECURITY.md.
